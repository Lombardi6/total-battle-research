TOTAL BATTLE RESEARCH CALCULATOR

Spustenie:
1. index.html + app.js + style.css + research.json musia byť v rovnakom priečinku.
2. Na hostingu ich nahraj spolu.
3. Na localhost/HTTPS bude fungovať fetch research.json.

Je to reálna klientská JavaScript aplikácia:
- vyhľadávanie
- 418 výskumov / 14 vetiev
- výber levelov
- VP/CP výpočet
- rozpočet
- filtre
- localStorage progres
- mobilné rozhranie

Pre úplne lokálne otvorenie cez file:// môže browser blokovať načítanie research.json.
Vtedy použi jednoduchý lokálny server alebo nahraj súbory na webhosting.
